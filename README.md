# 🔐 SecureSphere

SecureSphere is a simple **user login and registration web application** developed for Web Programming Lab.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- bcrypt

## ✨ Features

- User Registration
- User Login
- Password Hashing
- MongoDB Database
- Dashboard
- Logout

## 📁 Project Structure

```text
SecureSphere/
├── public/
│   ├── index.html
│   ├── signup.html
│   ├── dashboard.html
│   ├── script.js
│   └── style.css
├── server.js
├── package.json
├── package-lock.json
├── .gitignore
└── readme.md
```

## ▶️ Run the Project

Install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

Open:

```text
http://localhost:3000
```

## 🔐 Database

MongoDB Atlas is used to store user details.

Passwords are securely hashed using bcrypt.
